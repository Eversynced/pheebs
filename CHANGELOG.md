## 1.0.0 (2026-09-23)

First public release.

### Features

* **claude:** capture mid-session model switches
* **config:** make the background self-update opt-in, and have doctor report versions
* **config:** ship no endpoint, making pheebs local-only by default
* **contract:** require a unit on every quality signal
* **cursor:** capture effort, fast_mode and rule-attachment counts
* distribute via npm instead of private GitHub releases
* **hooks:** capture per-call run_in_background
* **hooks:** wire the Claude Code InstructionsLoaded hook
* **insights:** render the report in the terminal

### Bug Fixes

* **contract:** document the Allow header, and clamp an absurd window
* **insights:** count the value floor when deciding a chart fits
* **insights:** do not report a count that is not a whole number
* **insights:** drop a carriage return between JSON tokens on --json
* **insights:** report a mid-body timeout as a timeout
* **insights:** strip a surrogate with no partner before measuring
* **insights:** treat the /insights payload as untrusted input
* restore the Codex permission_mode capture
* **update:** never let a registry response reach a shell
